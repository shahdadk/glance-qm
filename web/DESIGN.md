# kompX companion design

## Product surface

The browser is a compact companion for the actual Meta glasses app. The user asked to remove the dashboard and visible room-ID workflow. The main flow therefore shows only listening status, one useful thought, and simple Now, Tasks, and Summary views. Connection pairing and full diagnostic capabilities live under Settings → Advanced.

## Visual system

Use a single column, black background, high-contrast white text, restrained gray separators and secondary text. System sans-serif carries all roles. The cue is the largest element at 26–30 px, with a generous fixed reading area and stable source disclosure. The listening button is plain white with black text. Controls have 44 px minimum targets, visible focus and reduced-motion support.

No dashboard grids, room-ID entry forms, provider panels in the main flow, marketing hero, decorative motion, gradients, shadows, or generated imagery. The established Glance attention-budget and evidence principles remain; its previous violet/column layout has been superseded by the user's explicit simpler direction.

## Interaction

Start resumes a cached session or creates a default session without an additional form. Microphone permission remains explicit. Pause stops browser capture and pauses the runtime. Summary provides Finish & summarize. Tasks preserve exact calendar preview and confirmation. A share icon creates a session link without exposing the token.
